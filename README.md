
# GenTrack
## Smart Generator Management System

### Project Description
GenTrack is a web-based system designed to help generator owners manage their generators and subscribers.

### Main Features
- Generator Management
- Subscriber Management
- Meter Reading
- Electricity Bill Generation
- Payment Management
- AI Assistant

### Technologies
- React.js
- Node.js
- Express.js
- PostgreSQL

### Project Goal
To make generator management easier, faster, and more organized.
